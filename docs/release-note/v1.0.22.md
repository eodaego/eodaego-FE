# [주요 변경사항 — 애플 제출용]

[한국어]

이번 버전의 주요 변경사항입니다.

1. 마이페이지 개편
- 마이페이지 디자인을 새롭게 바꿨습니다.
- 마이페이지에서 닉네임을 변경할 수 있습니다.
- 마이페이지에서 회원 탈퇴를 할 수 있습니다.
- 마이페이지에서 약관 내용을 다시 볼 수 있습니다.

2. 닉네임 설정 개선
- 닉네임을 정할 때 이미 사용 중인 이름인지 바로 확인할 수 있습니다.
- 닉네임 길이 제한을 안내합니다.
- 입력한 닉네임을 한 번에 지울 수 있는 지우기 버튼을 추가했습니다.

3. 약관 동의 화면 개편
- 약관 동의 화면을 보기 쉽게 새로 만들었습니다.
- 마케팅 정보 수신 동의 항목을 추가했습니다.

4. 로그인 및 가입 과정 개선
- 가입 과정이 중간에 끊기던 문제를 수정했습니다.
- 로그인이 더 안정적으로 동작합니다.

5. 안정성 개선 및 버그 수정
- 회원 탈퇴 처리가 더 안정적으로 동작합니다.

==========

[English]

Key changes in this version:

1. My Page Redesign
- Refreshed the My Page screen with a new design.
- You can change your nickname in My Page.
- You can delete your account in My Page.
- You can review the terms again in My Page.

2. Nickname Improvements
- Nickname availability is checked instantly when you choose a name.
- Nickname length limits are now shown.
- Added a clear button to erase the entered nickname at once.

3. Terms Agreement Screen Redesign
- Rebuilt the terms agreement screen to be easier to read.
- Added a marketing consent item.

4. Sign-in and Sign-up Improvements
- Fixed an issue where the sign-up flow could be interrupted midway.
- Sign-in now works more reliably.

5. Stability Improvements & Bug Fixes
- Account deletion now works more reliably.
