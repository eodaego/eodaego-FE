# [주요 변경사항 — 애플 제출용]

[한국어]

이번 버전의 주요 변경사항입니다.

1. 산책 코스 추천
- 원하는 조건을 다섯 단계로 골라 코스를 추천받을 수 있습니다.
- 조건 선택지를 아이콘 격자로 바꾸고, 다음으로 넘어가는 버튼을 화면 아래에 고정했습니다.
- 추천 결과 목록과 코스를 만드는 동안 보이는 대기 화면을 정리하고 안내 문구를 추가했습니다.

2. 코스 즐겨찾기
- 마음에 드는 코스를 즐겨찾기에 담고 목록에서 모아 볼 수 있습니다.
- 즐겨찾기 목록과 정렬 순서가 서버에 저장된 내용과 항상 같게 표시됩니다.

3. 공원 지도
- 공원 화면을 실제 지도로 바꿨습니다.
- 지도에서 장소를 누르면 해당 장소의 정보 카드가 나타납니다.
- 지도 아래 코스 목록에서 즐겨찾기와 장소 선택을 바로 할 수 있습니다.

4. 홈 화면
- 홈 화면 구성을 새로 정리했습니다.
- 날씨 카드에서 현재 공원 혼잡도를 함께 확인할 수 있습니다.

5. 도감
- 퀴즈 보상을 받으면 해당 항목이 도감에 자동으로 수집됩니다.
- 도감 목록을 세 칸 그리드로 바꾸고 상세 화면을 정리했습니다.

6. 그 외 개선
- 내 정보 화면에서 앱 버전을 확인할 수 있습니다.
- 앱 전체 문구를 더 읽기 쉽게 다듬었습니다.
- 촬영 화면의 안내 프레임을 모서리 표시 방식으로 바꿨습니다.

7. 안정성 개선 및 버그 수정
- 코스 추천이 오래 걸려도 중간에 끊기지 않도록 수정했습니다.
- 즐겨찾기를 짧은 시간에 여러 번 누를 때 발생하던 오류를 수정했습니다.
- 추천 결과 화면에서 뒤로 가면 조건 선택 화면으로 되돌아가던 문제를 수정했습니다.
- 축하 효과가 버튼을 가리던 문제를 수정했습니다.

==========

[English]

Key changes in this version:

1. Walking Course Recommendations
- Choose your preferences across five steps to get course recommendations.
- Options are now shown as an icon grid, with the next-step button fixed at the bottom of the screen.
- Improved the recommendation results list and the waiting screen shown while a course is being created, with added guidance text.

2. Course Favorites
- Save courses you like to favorites and browse them in one place.
- The favorites list and its sort order now always match what is saved on the server.

3. Park Map
- The park screen now uses a real map.
- Tapping a place on the map shows an information card for that place.
- You can add favorites and select places directly from the course list below the map.

4. Home Screen
- Reorganized the home screen layout.
- The weather card now also shows current park congestion.

5. Collection
- Items are automatically added to your collection when you receive a quiz reward.
- The collection list is now a three-column grid, with a cleaner detail screen.

6. Other Improvements
- The app version is now shown on the My Info screen.
- Refined wording throughout the app for easier reading.
- The camera screen guide frame now uses corner markers.

7. Stability Improvements & Bug Fixes
- Fixed an issue where course recommendations could be interrupted when they took longer than usual.
- Fixed an error that occurred when tapping the favorite button several times in quick succession.
- Fixed an issue where going back from the results screen returned you to the preference selection screen.
- Fixed an issue where the celebration effect covered the button.
