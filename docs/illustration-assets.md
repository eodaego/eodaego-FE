# 일러스트 에셋 명세

> 대상: 데모 동선 5화면 (홈 · 촬영 · 퀴즈 · 축하 · 도감)
> 관련 이슈: UI 전면 개편
> 코드는 이미지가 없어도 동작한다 — 없으면 카테고리 아이콘으로 대체된다. 파일을 넣으면 자동으로 바뀐다.

---

## 1. 전체 목록 — 11장

| # | 경로 | 쓰이는 곳 |
| --- | --- | --- |
| 1~9 | `assets/images/catalog/{code}.png` | 도감 목록·상세, 퀴즈 문제, 축하 카드 |
| 10 | `assets/images/mascot/celebrate.png` | 축하 화면 |
| 11 | `assets/images/course/today.png` | 홈 추천 코스 카드 |

### 도감 항목 9종

파일명은 목 데이터의 `code` 값을 그대로 쓴다.

| 파일명 | 이름 | 카테고리 |
| --- | --- | --- |
| `A001.png` | 수달 | 동물 |
| `A002.png` | 너구리 | 동물 |
| `A003.png` | 공작 | 동물 |
| `P001.png` | 소나무 | 식물 |
| `P002.png` | 벚나무 | 식물 |
| `P003.png` | 수국 | 식물 |
| `L001.png` | 음악분수 | 장소 |
| `L002.png` | 팔각당 | 장소 |
| `L003.png` | 동물원 | 장소 |

**미수집 15종은 만들지 않는다.** 도감에서 `?` 카드로 그려지고 상세도 열리지 않는다. 나중에 수집 대상을 늘릴 때 같은 규칙으로 추가하면 된다.

---

## 2. 규격

| 항목 | 값 | 이유 |
| --- | --- | --- |
| 포맷 | PNG, **배경 투명** | 크림 배경·흰 카드·원형 썸네일 어디에 올려도 맞아야 한다 |
| 도감 9종 크기 | **1024 × 1024** (정사각) | 목록 썸네일 48 / 퀴즈 200 / 상세 340 세 크기로 쓰인다. 3배 밀도 기준 최대 1020이라 1024 한 장이면 전부 커버된다 |
| 마스코트 | **1024 × 1024**, 투명 | 축하 화면에서 약 160 |
| 코스 씬 | **1200 × 540** (가로), 배경 있어도 됨 | 카드 안에 꽉 차게 들어간다 |

정사각 안에 **여백을 조금 두고** 대상을 중앙 배치해 주세요. 원형으로 잘릴 때(목록 썸네일) 가장자리가 잘리지 않습니다.

---

## 3. 스타일

참조 시안과 같은 방향으로 맞춥니다.

- 부드러운 플랫 일러스트. 굵은 검은 외곽선 없음
- 따뜻한 색감, 둥근 형태 — 어린이 그림책 톤
- 그림자·그라데이션 최소 (앱 전체가 플랫 컨셉)
- 사진과 섞지 않기 — **9종 전부 일러스트로 통일**

> 참조 시안의 도감 상세만 사자 실사 사진이었는데, 나머지 화면이 전부 일러스트라 섞으면 톤이 깨집니다. 일러스트로 통일하는 걸 권합니다.

### 카테고리별 색 힌트

배경이 투명이라 강제는 아니지만, 대상 자체의 색이 카테고리 색과 어울리면 화면이 정돈됩니다.

| 카테고리 | 앱 색 |
| --- | --- |
| 동물 | 주황 `#F58A3C` |
| 식물 | 초록 `#3DA35D` |
| 장소 | 파랑 `#4A9FE8` |

### 마스코트

참조 시안의 곰처럼 **탐험가 복장**(모자·스카프)이 앱 컨셉과 맞습니다. 축하 포즈 한 장이면 충분하고, 여유가 되면 아래 두 장을 더 받으면 다른 화면에도 씁니다.

- `celebrate.png` — 필수. 축하/환호 포즈
- `greeting.png` — 선택. 인사 포즈 (홈·스플래시)
- `thinking.png` — 선택. 갸웃하는 포즈 (퀴즈 오답, 빈 상태)

## 4. 넣는 방법

```
assets/images/
  catalog/
    A001.png  A002.png  A003.png
    P001.png  P002.png  P003.png
    L001.png  L002.png  L003.png
  mascot/
    celebrate.png
  course/
    today.png
```

`pubspec.yaml`에 `assets/images/` 등록은 코드 작업에서 함께 처리합니다. 파일만 위 경로에 넣어 주세요.

---

## 5. 없어도 되는 것

아래는 코드로 그리므로 이미지가 필요 없습니다.

- 컨페티 (도형으로 직접 그림)
- 카테고리 아이콘 (Material 아이콘 사용 중)
- 진행률 게이지, 뱃지, 버튼
- 촬영 화면 프레임

---

## 6. 우선순위

한 번에 다 못 만드시면 이 순서로 주세요. 앞에서부터 화면이 하나씩 살아납니다.

1. **`mascot/celebrate.png`** — 축하 화면이 가장 허전하고, 데모의 하이라이트다
2. **`catalog/A001~A003.png`** (수달·너구리·공작) — 퀴즈가 동물부터 돈다
3. **`catalog/P001~P003.png`** (소나무·벚나무·수국)
4. **`catalog/L001~L003.png`** (음악분수·팔각당·동물원)
5. **`course/today.png`** — 홈 카드. 없으면 카드가 텍스트만으로 나온다
