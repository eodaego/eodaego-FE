### 📌 작업 개요

코스 생성 대기 화면의 고양이에 풍선 상호작용 추가. 누르고 있으면 서서히 부풀고, 한계에 가까워지면 떨림이 커지고 빨라지며, 놓으면 통통 튀면서 제자리로 돌아온다. 함께 앱 공용 버튼에 진동 피드백을 통일하고, 진동 호출을 상수 한곳(`AppHaptics`)으로 모았다.

**보고서 파일**: `.report/20260810_#33_대기화면_고양이_풍선_상호작용과_공용버튼_진동.md`

### 🎯 구현 목표

- AI 코스 생성 대기 시간(수 초 이상)이 지루하지 않도록 고양이를 눌러볼 수 있게 만들기
- 공용 버튼(`AppButton`)에 탭 진동 추가 — 뒤로가기 버튼만 진동이 있던 비일관성 해소
- 진동 종류를 상수로 분리해 추후 "진동 끄기" 설정 대비

### ✅ 구현 내용

#### 진동 상수 분리
- **파일**: `lib/core/constants/app_haptics.dart` (신규)
- **변경 내용**: `AppHaptics` 클래스에 진동 3종 정의 — `tap`(가벼운 탭), `tick`(잔진동), `thud`(묵직한 진동)
- **이유**: 진동을 쓰는 곳이 모두 이 한곳을 거치게 하여, 진동 끄기 설정이 생기면 여기만 수정하면 되도록 구성

#### 공용 버튼 진동 적용
- **파일**: `lib/core/widgets/app_button.dart`
- **변경 내용**: 탭 시 `AppHaptics.tap()` 호출. 비활성·로딩 상태는 `onPressed`가 null이라 자동으로 진동 제외
- **이유**: 모든 공용 버튼이 같은 감촉을 갖도록 통일

#### 뒤로가기 버튼 진동 경로 교체
- **파일**: `lib/core/widgets/previous_button.dart`
- **변경 내용**: `HapticFeedback.lightImpact()` 직접 호출을 `AppHaptics.tap()`으로 교체, 임시 주석 제거
- **이유**: 진동 호출 단일 경로 유지

#### 대기 화면 고양이 풍선 상호작용
- **파일**: `lib/features/course/presentation/widgets/course_loading_cat.dart` (신규)
- **변경 내용**: 기존 페이지 로딩 브랜치에 있던 고양이 Lottie + 안내 문구를 전용 위젯으로 분리하고 상호작용 구현
- **이유**: 페이지 전체(Riverpod 프로바이더 포함)를 띄우지 않고 위젯 단위로 테스트 가능

#### 코스 추천 페이지 정리
- **파일**: `lib/features/course/presentation/pages/course_recommend_page.dart`
- **변경 내용**: 로딩 브랜치를 `const Center(child: CourseLoadingCat())` 한 줄로 교체
- **이유**: 페이지는 상태 분기만 담당하고 대기 화면 구성은 위젯에 위임

### 🔧 주요 변경사항 상세

#### 풍선 상호작용 동작 흐름

| 단계 | 크기 | 흔들림 | 진동 |
|---|---|---|---|
| 가만히 | 1.0배 | 없음 | — |
| 누르는 중 | 3초에 걸쳐 일정 속도로 4.0배까지 | 거의 없음 | 누른 순간 1회 (tap) |
| 한계 접근 | 크기도 ±3% 파르르 | 진폭 커지고 속도도 빨라짐 (1.2→6Hz) | 흔들림 한 바퀴마다 잔진동 (tick) |
| 한계 도달 | 4.0배에서 떨며 유지 | 최대 ±5도 | 묵직한 진동 1회 (thud) |
| 놓는 순간 | bounceOut으로 통통 튀며 복귀 (650ms) | 찌그러졌다 펴지는 변형 ±7% | — |
| 여운 | 1.0배 | 1.1초에 걸쳐 잦아듦 | — |

#### 내부 구조

- `_inflate` (AnimationController, 0~1): 부푼 정도의 원천. 다시 누르면 남은 거리만큼만 시간을 배분해 끊었다 눌러도 같은 속도로 이어 부풂
- `_phase` (Ticker + ValueNotifier): 사인파 위상을 직접 누적. 진동수가 긴장도에 따라 실시간으로 변해 "점점 빨리 떨리는" 효과 구현 — 고정 주기 컨트롤러로는 불가능한 부분
- `_flap` (AnimationController): 손을 뗀 순간의 부푼 정도를 물려받아 1.1초 선형 감쇠. 크기 복귀(650ms)보다 오래 남아 몸이 먼저 돌아오고 팔랑임이 뒤에 남음
- 긴장도는 `easeInQuint(inflate)` 하나에서 파생되며, 떨림 진폭·속도·크기 펄스·잔진동 게이트가 모두 이 값을 공유

**특이사항**:
- 확대는 `Transform` 기반이라 레이아웃에 영향 없음 — 고양이가 화면 밖으로 넘쳐도 아래 안내 문구는 제자리 유지
- 조절 상수는 파일 상단에 모아둠 (`_maxScale`, `_growDuration`, `_trembleFastHz`, `_maxWobbleAngle` 등)
- 흔들림 위상 ticker는 항상 돌지만 가만히 있을 때는 흔들림 세기가 0이라 화면 변화 없음. 전력 이슈가 생기면 누르는 동안만 돌리는 방식으로 전환 가능 (코드에 주석으로 명시)

### 📦 의존성 변경

- `vibration` 패키지 제거 — 선언만 있고 실제 사용처 없었음. 진동은 모두 OS 기본 API(`HapticFeedback`) 사용으로 통일 (iOS 기본 탭 감촉과 자연스럽게 일치, 권한 불필요)
