## 제목

⚙️ [기능추가][Flutter][날씨] 현재 날씨 API 연동과 날씨 상세 화면 추가

## 본문

## 📝 현재 문제점

- 홈 상단 바의 날씨가 목업 고정값(맑음 24도)이라 실제 공원 날씨를 확인할 수 없음
- 날씨 기능에 data/domain 계층이 없어 서버 데이터를 받아올 통로 자체가 없는 상태
- 서버는 현재 날씨와 함께 3.5일치 시간대별 예보를 함께 내려주는데 보여줄 화면이 없어 대부분 버려짐
- 나들이 앱 특성상 이따 비가 오는지, 내일 날씨가 어떤지가 실제 방문 결정에 쓰이는 정보임

## 🛠️ 해결 방안 / 제안 기능

- 현재 날씨 조회 연동 (기온, 습도, 풍속, 하늘 상태, 강수 형태)
- 홈 상단 바를 날씨 전용으로 정리하고 실제 데이터로 교체
- 홈 날씨 바를 누르면 진입하는 날씨 상세 화면 신규 추가
- 시간대별 예보를 날짜 단위로 끊어 상세 화면에 표시

## ⚙️ 작업 내용

- 홈 상단 바의 목업 날씨를 서버 데이터로 교체하고 목 데이터 파일 제거
- 홈 상단 바에서 혼잡도 뱃지 제거 (혼잡도는 서버 API가 없어 목업 상태였음)
- 홈 상단 바 전체를 탭 영역으로 만들어 날씨 상세 화면으로 이동
- 날씨 상세 화면에 현재 기온, 습도, 바람, 하늘 상태 표시
- 시간대별 예보에서 이미 지나간 시각을 걸러내고 남은 예보만 표시
- 시간대별 예보를 날짜 구분선으로 끊어 세로 목록으로 표시
- 하늘 상태와 강수 형태에 맞는 아이콘 매핑 (강수가 하늘 상태보다 우선)
- 서버에 새 하늘 상태나 강수 형태가 추가돼도 앱이 깨지지 않도록 처리
- 조회 실패와 로딩 상태를 홈과 상세 화면 각각에 맞게 표시

## ⚠️ 확인 필요 사항

- 서버가 내려주는 예보 시각에 타임존 정보가 없어 기기 시간대에 따라 예보가 어긋날 수 있음. 한국 시간 기준으로 고정해 처리한다.
- 응답의 현재 기온과 시간대별 기온의 출처가 달라 값이 서로 다르게 보일 수 있음. 관측 시각과 수집 시각의 간격을 확인해 표시 기준을 정한다.
- 이번 응답에서 확인된 하늘 상태는 맑음과 구름많음 두 가지, 강수 형태는 없음 한 가지뿐이다. 나머지 값의 실제 표기를 백엔드에 확인한다.

## 📌 범위 제외

- 공원 혼잡도는 서버 API가 없어 이번 범위에서 제외한다. API가 준비되면 별도 이슈로 진행한다.
- 습도와 풍속은 상세 화면에만 노출하고 홈에는 넣지 않는다.
- 날씨 조회는 로그인이 필요한 API다. 공개 정보임에도 인증을 요구하는 부분은 백엔드와 별도로 논의한다.
