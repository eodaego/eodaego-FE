## 본문

## 📝 현재 문제점

- 마이페이지의 닉네임 바꾸기와 탈퇴하기 버튼이 "준비 중이에요" 안내만 띄우고 실제로 동작하지 않음
- 닉네임은 가입 온보딩에서만 정할 수 있고, 이후 바꿀 방법이 없음
- 약관 동의도 가입 시 한 번뿐이라, 나중에 전문을 다시 보거나 마케팅 수신 동의를 철회할 경로가 없음
- 회원탈퇴는 서버 응답 형식이 정본과 어긋나 있어, 화면에 연결하면 그대로 실패함
- 마이페이지 프로필 영역이 서버에 존재하지 않는 아바타 자리를 차지하고 있음

## 🛠️ 해결 방안 / 제안 기능

- 마이페이지에서 닉네임을 바꿀 수 있게 한다 (중복·형식 오류 안내 포함)
- 마이페이지에서 회원탈퇴를 실행할 수 있게 한다 (되돌릴 수 없음을 확인받은 뒤 진행, 완료 시 로그인 화면으로 이동)
- 약관 및 정책 화면을 추가해 4종 전문을 다시 볼 수 있게 하고, 마케팅 수신 동의는 그 자리에서 켜고 끌 수 있게 한다
- 서버가 주지 않는 아바타 표시를 걷어내고 닉네임 중심으로 프로필 영역을 정리한다

## ⚙️ 작업 내용

- 회원탈퇴 응답 형식을 정본에 맞게 정정
- 약관 및 정책 화면 추가 (전문 열람, 마케팅 수신 동의 토글)
- 마이페이지 프로필 영역 정리
- 정본에 없는 회원 정보 조회 관련 잔재 코드 제거
