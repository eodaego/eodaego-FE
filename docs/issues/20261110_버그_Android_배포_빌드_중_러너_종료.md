📝 현재 문제점
---

- v1.0.41 배포에서 Android Play 내부 배포 워크플로우(`PROJECT-FLUTTER-ANDROID-PLAYSTORE-INTERNAL-CICD`)가 3번 연속 실패했다. iOS TestFlight 배포는 같은 커밋으로 성공했다.
- 세 번 모두 컴파일 오류나 Gradle 오류는 없었다. 릴리스 AAB 빌드(`bundleRelease`)의 코드 축소(R8) 단계나 그 직전에 GitHub 러너가 종료 신호를 받고 끊겼다(`The runner has received a shutdown signal`, exit code 143).
- 같은 코드로 로컬에서 `flutter build appbundle --release`는 정상 완료된다. PR CI의 디버그 APK 빌드도 같은 러너 이미지에서 통과했다.

🛠️ 해결 방안 / 제안 기능
---

- `android/gradle.properties`가 Gradle에 힙 8GB, 메타스페이스 최대 4GB를 주고 있다. GitHub 표준 러너(메모리 16GB)에서 Kotlin 데몬과 R8까지 함께 돌면 메모리가 바닥나 러너가 끊길 수 있다고 본다(추정).
- Gradle 메모리 설정을 러너 크기에 맞게 낮추고 다시 배포해 확인한다.
