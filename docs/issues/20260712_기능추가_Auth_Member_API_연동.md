## 제목

⚙️ [기능추가][Auth][Member] 소셜 로그인 및 약관 동의 연동

## 본문

## 📝 현재 문제점

- 소셜 로그인(Google/Apple) 이후 앱 내부에서 백엔드 인증 및 회원 관리 플로우가 아직 연결되어 있지 않음
- 로그인 성공 응답의 `requiresAgreement`가 true인 경우, 약관 동의 화면과 API 연동이 되어야 신규/미동의 회원의 온보딩이 완료됨
- 로그인과 약관 동의는 하나의 온보딩 플로우로 이어지므로 함께 구현이 필요함

## 🛠️ 해결 방안 / 제안 기능

- 소셜 로그인 API 연동 (idToken 전달 → accessToken/refreshToken 발급)
- 토큰 재발급(reissue) 연동
- 로그아웃 연동
- 로그인 응답의 `requiresAgreement`, `firstLogin` 값에 따른 분기 처리
- 약관 동의 여부 조회 API 연동
- 약관 동의 여부 수정 API 연동
- 회원탈퇴 API 연동

## ⚙️ 작업 내용

- Auth: 로그인, 로그아웃, 토큰 재발급 API 연동
- Member: 약관 동의 조회/수정, 회원탈퇴 API 연동
- 로그인 → 약관 동의 온보딩 플로우 연결
