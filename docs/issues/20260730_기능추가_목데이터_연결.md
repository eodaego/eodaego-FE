## 제목

⚙️ [기능추가][Flutter][목데이터] USE_MOCK_DATA 켜면 예시 응답으로 화면이 동작하게 연결

## 본문

## 📝 현재 문제점

- USE_MOCK_DATA 플래그가 목 구현체와 실 구현체를 가르는 데 쓰인 적이 한 번도 없다. 실제 효과는 게스트 둘러보기 제한을 푸는 것 하나뿐이다
- 환경 설정 파일의 주석은 이 값으로 Repository를 분기한다고 적혀 있으나 그렇게 구현된 적이 없다
- 예제 환경 파일은 이 값이 켜진 상태로 배포되어, 예제를 복사한 사람은 목 데이터를 기대하지만 실제로는 서버를 호출한다
- 백엔드 없이 화면을 띄울 방법이 없어 시연이나 UI 작업에 제약이 있다
- 퀴즈는 백엔드 기능이 없고 한 문제가 화면에 직접 적혀 있어, 몇 번을 촬영해도 항상 같은 문제만 나온다

## 🛠️ 해결 방안 / 제안 기능

- USE_MOCK_DATA가 켜져 있으면 예시 응답 파일을 읽어 화면을 채운다
- 분기는 서버 통신을 담당하는 지점에서만 한다. 응답을 화면용 데이터로 바꾸는 과정은 목이든 실제든 같은 코드를 지나가게 해서, 목으로 본 화면이 실제 동작과 어긋나지 않게 한다
- 퀴즈 문항을 파일로 옮겨 여러 문제가 번갈아 나오게 한다

## ⚙️ 작업 내용

- 날씨 예시 응답 파일 추가와 화면 연결
- 도감 목록, 상세, 수집 현황 예시 응답 파일 추가와 화면 연결
- 퀴즈 문항 파일 추가와 촬영에서 축하 화면까지의 연결
- 예시 데이터의 날짜를 앱을 켠 날 기준으로 맞춘다. 고정 날짜를 그대로 두면 그 날이 지나는 순간 예보 목록이 비고 수집일이 미래로 보인다
- 사진은 기존 카테고리 아이콘 표시를 그대로 쓴다
- 환경 설정 주석과 예제 환경 파일을 실제 동작에 맞게 정리한다

## 📌 범위 제외

- 동식물 사진 파일. 앱 안에 쓸 수 있는 이미지가 없어 카테고리 아이콘으로 대체한다. 사진이 준비되면 별도로 진행한다
- 로그인 목 처리. 로그인 없이 화면을 둘러보는 것은 게스트 둘러보기가 이미 담당한다
- 사진 인식과 도감 수집. 해당 백엔드 기능이 준비된 뒤 별도 이슈로 진행한다
