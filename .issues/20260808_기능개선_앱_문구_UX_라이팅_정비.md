## 본문

## 📝 현재 문제점

- 앱에 노출되는 문구 약 150개를 전수 점검한 결과, 해요체와 경어 규칙은 잘 지켜져 있으나 세 갈래에서 규칙을 벗어난 문구가 남아 있음
- 부정형 문구가 남아 있어 사용자가 기능을 아예 쓸 수 없다고 오해할 수 있음 (찾는 이름이 없어요, 예보 정보가 아직 없어요, 아직 만나지 못했어요)
- 수동 표현이 남아 있음 (업데이트할 때가 됐어요)
- 한자어 명사를 붙여 쓴 문구가 여러 화면에 흩어져 있음 (약관 및 정책, 마케팅 정보 수신, 최근 저장순, 소요시간순, 저장 해제, 공식 약도 이미지, 필수 항목, 도감 상세, 미수집, 수집 완료)
- 같은 뜻을 화면마다 다르게 부름. 홈은 나의 도감, 마이페이지는 내 도감으로 갈림
- 실패 안내 문구가 두 가지 패턴으로 갈려 있음. 대부분은 못했어요 형태인데 로그인 화면 두 곳만 문제가 생겼어요 형태

## 🛠️ 해결 방안 / 제안 기능

- 부정형 문구를 긍정형으로 바꿔, 지금 할 수 있는 일을 알려주는 문장으로 정리한다
- 수동 표현을 능동형으로 바꾼다
- 한자어를 풀어써 아이가 읽어도 뜻이 통하게 한다
- 같은 대상을 부르는 이름을 한 가지로 통일한다
- 실패 안내는 못했어요 형태를 정본으로 삼고, 갈라져 있는 두 곳을 여기에 맞춘다
- 법정 문서 제목, 탈퇴 경고 문구, 서버가 내려주는 값, 탭과 카테고리 이름은 손대지 않는다

## ⚙️ 작업 내용

- 부정형 문구 3건을 긍정형으로 교체
- 수동 표현 1건을 능동형으로 교체
- 한자어 명사 문구 9건 풀어쓰기
- 도감 뱃지 라벨을 아직이에요 · 만났어요로 교체 (통계 라벨은 유지)
- 나의 도감을 내 도감으로 통일
- 로그인 화면 실패 안내 2건을 정본 패턴에 맞춤
- 다시 시도 버튼 4곳을 다시 불러오기로 교체
- 바뀐 문구를 검증하는 테스트 단정문 7개 파일 동기화
