## 제목

🚀 [기능개선][인터랙션] 대기 화면 고양이 탭 반응과 공용 버튼 진동 피드백 추가

## 본문

## 📝 현재 문제점

- 코스를 만드는 동안 AI 응답을 기다리는 시간이 길다. 화면에는 고양이 그림이 계속 돌아가지만 눌러도 아무 일이 없어, 기다리는 사람이 할 일이 없다
- 앱 전역에서 쓰는 공용 버튼을 눌러도 손끝에 아무 반응이 없다. 뒤로가기 버튼만 진동이 들어가 있어 버튼마다 감촉이 다르다
- 진동 세기를 부르는 방식이 코드 여기저기에 흩어져 있다. 나중에 세기를 바꾸거나 끄는 설정을 넣으려면 쓰인 곳을 모두 찾아다녀야 한다

## 🛠️ 해결 방안 / 제안 기능

- 대기 화면의 고양이를 누르면 살짝 커졌다가 손을 떼면 원래대로 돌아오게 한다. 누르는 동안만 커지고 놓으면 돌아오므로, 계속 눌러도 화면이 흐트러지지 않는다
- 고양이를 누를 때도 가벼운 진동을 함께 준다
- 공용 버튼을 누를 때 가벼운 진동을 준다. 비활성 상태나 로딩 중에는 진동을 주지 않는다
- 진동 종류를 상수로 한곳에 모으고, 뒤로가기 버튼을 포함해 진동을 쓰는 곳이 모두 이 상수를 거치게 한다. 나중에 진동 끄기 설정이 필요해지면 이 한곳만 손대면 된다

## ⚙️ 작업 내용

- 진동 상수 파일 추가
- 공용 버튼에 탭 진동 적용 (비활성·로딩 시 제외)
- 뒤로가기 버튼의 진동 호출을 새 상수로 교체
- 코스 대기 화면 고양이에 탭 확대 반응과 진동 적용
- 위젯 테스트 추가
