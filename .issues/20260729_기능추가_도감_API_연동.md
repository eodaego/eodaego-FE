## 제목

⚙️ [기능추가][Flutter][도감] 도감 목록·상세·요약 API 연동

## 본문

## 📝 현재 문제점

- 도감 목록, 도감 상세, 홈 진행률 카드가 모두 목업 데이터로 동작하고 있어 실제 수집 현황을 확인할 수 없음
- 도감 기능에 data/domain 계층이 없어 서버 데이터를 받아올 통로 자체가 없는 상태
- 목록, 상세, 요약은 같은 도감 도메인이라 함께 연동해야 화면 흐름이 완결됨

## 🛠️ 해결 방안 / 제안 기능

- 도감 목록 조회 연동 (카테고리 필터, 이름 검색)
- 도감 상세 조회 연동
- 도감 수집 현황 요약 연동

## ⚙️ 작업 내용

- 도감 목록 화면의 목업 데이터를 서버 데이터로 교체
- 카테고리(동물/식물/장소) 필터와 이름 검색 연결
- 미수집 항목은 상세로 들어갈 수 있되 이름과 설명을 물음표로 표시
- 수집한 항목만 상세 정보와 수집일 표시
- 홈 진행률 카드를 수집 현황 요약 데이터로 교체

## 📌 범위 제외

- 도감 항목 수집은 이번 범위에서 제외한다. 사진 인식 기능이 없어 어떤 항목을 수집할지 정할 방법이 없으므로, 인식 기능이 준비된 뒤 별도 이슈로 진행한다.
- 도감 화면을 확인하려면 테스트 계정에 수집 이력이 필요하다. 백엔드에 샘플 수집 데이터 준비를 요청한다.
