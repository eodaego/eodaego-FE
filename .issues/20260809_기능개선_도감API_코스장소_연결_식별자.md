## 제목

🚀 [기능개선][도감API] 코스 장소와 도감 항목을 연결할 식별자 노출 요청

## 본문

## 📝 현재 문제점

- 지도에서 코스 마커를 누르면 뜨는 장소 정보에 그 장소의 도감 수집 여부를 함께 보여주려 합니다. 그런데 코스 장소와 도감 항목을 정확히 연결할 식별자가 앱이 쓰는 API에 노출되어 있지 않습니다.
- 현재는 도감 목록 조회의 이름 검색으로 연결하고 있습니다. 이름 검색이 부분 일치라 다른 장소가 함께 조회됩니다. 예를 들어 코스 장소 "동물나라"로 검색하면 "동물나라 사육장"까지 결과에 포함됩니다.
- 잘못 짚으면 엉뚱한 도감 상세로 이동하게 됩니다. 프론트에서 이름 완전 일치로 한 번 더 거르고 있으나, 미수집 항목은 응답의 이름이 null로 내려와 이 검증이 걸리지 않습니다.
- 코스 장소 응답의 facilityId와 도감 항목의 externalId가 모두 "AI 서버 기준 ID"로 설명되어 있어 같은 값으로 보입니다. 다만 externalId는 관리용 도감 항목 조회에만 있고, 앱이 쓰는 도감 목록 조회에는 없습니다.

## 🛠️ 해결 방안 / 제안 기능

- 먼저 확인 부탁드립니다. 코스 장소 응답의 facilityId와 도감 항목의 externalId가 같은 값이 맞는지 확정이 필요합니다.
- 같은 값이라면 아래 중 편한 방식으로 부탁드립니다.
  - 도감 목록 조회 응답 항목에 externalId 필드 추가
  - 또는 도감 목록 조회에 facilityId 필터 파라미터 추가
- 둘 중 하나만 있어도 이름 부분 일치로 인한 오연결이 사라집니다.
- 관리용 도감 항목 전체 조회에 externalId가 있는 것은 확인했습니다. 다만 이 엔드포인트는 회원의 수집 여부와 무관하게 도감 원본을 모두 내려주므로 앱에서는 사용하지 않습니다. 미수집 항목의 이름과 이미지가 노출되면 수집 동기가 사라집니다.

## ⚙️ 작업 내용

- 백엔드: facilityId와 externalId의 동일성 확인 후 회신
- 백엔드: 도감 목록 조회 응답 또는 필터에 코스 장소 연결용 식별자 노출
- 백엔드: API 문서 변경 이력 갱신
- 프론트엔드: 코스 장소 응답에서 facilityId 수신 (현재는 받지 않고 있음)
- 프론트엔드: 도감 조회 기준을 이름에서 식별자로 교체
- 프론트엔드: 이름 기반 연결로 동작하도록 임시 배선은 완료된 상태이며, 위 필드가 추가되면 조인 기준만 교체하면 됩니다
