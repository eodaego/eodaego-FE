## 제목

🚀 [기능개선][코스추천] 코스 추천 선택 화면을 아이콘 그리드와 하단 고정 버튼으로 정비

## 본문

## 📝 현재 문제점

- 희망 체류시간과 동행 유형 선택지에 이모지 8개를 그대로 쓰고 있어, 기기와 OS 버전에 따라 그림이 달라지고 앱의 그림체와도 겉돈다
- 출입문 11개와 관심분야 7개를 알약 모양 칩으로 나열해, 항목 폭이 제각각이라 눈이 훑기 어렵고 누를 곳도 좁다
- 다음과 건너뛰기 버튼이 스크롤 안에 들어 있어 스텝마다 위치가 달라지고, 화면을 내려야 보이는 경우가 있다
- 같은 역할의 버튼인데 스텝마다 생김새가 다르다. 어떤 스텝은 밑줄 없는 작은 글씨 버튼, 어떤 스텝은 폭 240 버튼이라 로그인 화면의 풀폭 버튼과도 어긋난다
- 선택 후 자동으로 다음 스텝으로 넘기는 예약이 겹칠 수 있어, 짧은 간격으로 다시 고르면 두 스텝을 건너뛸 수 있다

## 🛠️ 해결 방안 / 제안 기능

- 선택지의 이모지를 모두 걷어내고 아이콘으로 바꾼다. 필요한 15개가 모두 기본 아이콘 세트에 있어 새 패키지는 붙이지 않는다
- 칩 나열을 격자로 바꾼다. 항목이 많은 스텝은 3열로 라벨만, 항목이 적은 스텝은 2열로 아이콘과 보조 설명까지 담는다
- 출입문에는 아이콘을 넣지 않는다. 11개가 모두 문이라 같은 그림이 반복되면 정보를 주지 못한다
- 다음과 건너뛰기 버튼을 스크롤 밖 화면 하단에 고정하고, 로그인 화면과 같은 좌우 꽉 찬 크기로 통일한다
- 자동으로 넘어가는 흐름은 그대로 둔다. 하단 버튼은 지금 무엇이 골라졌는지 보여주면서, 기다리지 않고 바로 넘어가고 싶은 사람에게 지름길이 된다
- 관심분야는 여러 개를 고르는 스텝이라 자동으로 넘기지 않고 버튼으로만 넘어간다
- 자동 넘김 예약을 하나만 유지하도록 고쳐, 다시 고르면 앞선 예약이 취소되게 한다

## ⚙️ 작업 내용

- 체류시간 3종과 동행 유형 5종의 이모지를 아이콘으로 교체
- 관심분야 7종에 아이콘 부여
- 출입문 입구와 출구 두 스텝을 3열 격자로 교체
- 관심분야 스텝을 3열 격자로 교체
- 체류시간과 동행 스텝을 2열 격자로 교체하고 보조 설명 유지
- 5개 조건 스텝에 하단 고정 버튼 배치와 상태별 라벨 규칙 적용
- 자동 넘김 예약 중복 문제 수정
- 바뀐 화면 구성에 맞춰 위젯 테스트 정비
