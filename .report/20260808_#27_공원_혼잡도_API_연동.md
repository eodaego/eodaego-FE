# 공원 현재 혼잡도 API 연동

### 📌 작업 개요

백엔드에 `GET /api/1/congestion/current`가 추가되어 홈 날씨 카드에 공원 현재 혼잡도를 표시하도록 연동.

#20(날씨 API 연동) 당시 "혼잡도는 서버 API가 없어 이번 범위에서 제외"로 남겨뒀던 항목을 처리. 코드에 남아 있던 "혼잡도·미세먼지는 서버 API가 없어 넣지 않는다" 주석도 함께 정리.

### 🎯 구현 목표

- 현재 공원 혼잡도 조회 연동 (등급·한글 라벨·수집 시각)
- 홈 날씨 카드 하단에 혼잡도 한 줄 추가
- 서버가 모르는 등급을 내려줘도 앱이 깨지지 않게 처리
- 조회 실패 시 혼잡도 줄만 감추고 날씨는 그대로 유지

### ✅ 구현 내용

#### 혼잡도 도메인 엔티티 추가

- **파일**: `lib/features/weather/domain/entities/congestion_entity.dart` (신규)
- **변경 내용**: `CongestionLevel` enum 4종(여유·보통·약간 붐빔·붐빔)과 `CongestionEntity` 클래스 추가
- **이유**: 등급별 색 분기가 필요한데 서버는 문자열만 준다. `DogamCategory`와 동일한 `label`/`serverValue`/`color` 구조로 통일

#### 혼잡도 DTO 및 API 클라이언트 연동

- **파일**: `lib/features/weather/data/models/congestion_model.dart` (신규), `weather_remote_datasource.dart`, `api_endpoints.dart`
- **변경 내용**: 응답 DTO 추가, 기존 날씨 DataSource에 `getCurrentCongestion()` 메서드 추가
- **이유**: 혼잡도는 홈 날씨 카드 한 줄에만 쓰인다. 별도 feature 폴더를 만들면 파일만 4개 늘고 얻는 게 없어 weather feature에 얹음

#### Repository 변환 및 Provider 추가

- **파일**: `weather_repository_impl.dart`, `weather_repository.dart`, `weather_provider.dart`
- **변경 내용**: DTO → Entity 변환, `DioExceptionHandler` 경유 에러 처리, `currentCongestionProvider` 추가
- **이유**: 프로젝트의 기존 계층 규칙 그대로 적용

#### 목 데이터 대응

- **파일**: `assets/mock/congestion_current.json` (신규), `weather_mock_datasource.dart`
- **변경 내용**: 픽스처 추가, 목 DataSource에 동일 메서드 구현
- **이유**: `.env.example`이 `USE_MOCK_DATA=true`라 신규 개발자·CI가 목 모드로 시작한다. 목 경로가 없으면 홈 화면이 깨짐

#### 홈 날씨 카드에 혼잡도 줄 추가

- **파일**: `lib/features/home/presentation/pages/home_page.dart`
- **변경 내용**: `_WeatherCardData`를 `ConsumerWidget`으로 전환하고, 최고/최저·습도 줄 아래에 등급 색 점 + 라벨 한 줄 추가
- **이유**: 별도 카드를 만들면 홈 세로 길이만 늘어난다. 날씨와 혼잡도는 "지금 나가도 될까"라는 같은 질문에 답하는 정보라 한 카드에 묶는 게 자연스러움

### 🔧 주요 변경사항 상세

#### CongestionLevel.fromServer

서버가 모르는 등급 문자열을 주면 기본값으로 욱여넣지 않고 `null`을 반환. `DogamCategory.fromServer`와 같은 방침.

**특이사항**:
- API 문서상 서울시가 기존 4단계 외에 새 등급을 추가하면 `level`이 `null`로 내려온다. 이때도 `label`에는 원본 한글 문자열이 담기므로, 색 분기만 기본색(`AppColors.muted`)으로 두고 라벨은 그대로 표시
- 이 경우에도 HTTP 상태는 200이다. 에러가 아님

#### 혼잡도 조회 실패 처리

`loading`과 `error` 모두 `SizedBox.shrink()`로 그 줄만 사라지게 처리.

**특이사항**:
- 503(`AI_SERVER_UNAVAILABLE`)은 AI 서버 연결 실패나 수집 데이터 부재로 발생하며, **예외 상황이 아니라 정상 시나리오**다. 에러 문구를 띄우면 날씨 카드 전체 신뢰가 깎임
- 게스트는 상위 `_WeatherCard`가 카드 전체를 이미 숨기므로 별도 처리 불필요

#### collectedAt 미표시

응답의 수집 시각은 엔티티에 담지만 화면에는 노출하지 않음.

**특이사항**:
- API 문서에 "AI 서버가 원본을 가져온 시각이며 서울시 기준 시각보다 수십 분 늦을 수 있다"고 명시. "○○분 전 기준"으로 표기하면 실제보다 이르게 보여 사용자를 오도함

### 🎨 등급별 색상

기존 디자인 토큰만 사용. 새 색 추가 없음.

| 등급 | 라벨 | 토큰 |
|---|---|---|
| RELAXED | 여유 | `AppColors.primary` (초록) |
| NORMAL | 보통 | `AppColors.place` (파랑) |
| SLIGHTLY_CROWDED | 약간 붐빔 | `AppColors.animal` (주황) |
| CROWDED | 붐빔 | `AppColors.danger` (빨강) |
| (매핑 실패) | 원본 문자열 | `AppColors.muted` (회색) |
