# 마이페이지 디자인 개편

### 📌 작업 개요
마이페이지(내 정보) 화면 디자인 개편. 프로필 헤더·수집 통계 카드·메뉴 리스트를 새 레이아웃으로 전환하고, 옛 레이아웃 기준으로 작성된 위젯 테스트를 새 디자인 기준으로 교체. 탈퇴·로그아웃 로직과 다이얼로그 동작은 변경하지 않음.

**보고서 파일**: `.report/20260729_#15_마이페이지_디자인_개편.md`

### 🎯 구현 목표
- 프로필 헤더: 중앙 정렬 닉네임 + 연필 아이콘 → 좌측 닉네임 + 우측 "닉네임 바꾸기 ›" 텍스트 링크
- 수집 통계: 카드 2장 → 카드 1장을 세로 구분선으로 2분할 (수집률 | 모은 도감)
- 메뉴: 약관·로그아웃·탈퇴를 헤어라인 구분선 리스트 행으로 전환
- 기존 탈퇴/로그아웃 플로우는 UI만 바뀌고 동작은 동일하게 유지

### ✅ 구현 내용

#### 마이페이지 레이아웃 개편 (핵심)
- **파일**: `lib/features/user/presentation/pages/my_page.dart`
- **변경 내용**: 화면을 `_ProfileHeader` / `_StatsCard` / `_MenuRow` 세 개의 private 위젯으로 재구성
- **이유**: 카드 나열 구조를 정보 위계가 있는 리스트형 레이아웃으로 정리해 가독성과 탐색성 개선

#### 탈퇴 플로우 테스트 갱신
- **파일**: `test/features/user/presentation/pages/my_page_delete_account_test.dart`
- **변경 내용**: 옛 레이아웃(카드 버튼) 셀렉터를 새 메뉴 행 기준으로 교체. 확인/취소/오입력/실패/로컬 정리 실패/404 멱등 케이스 유지. "로그인한 사용자에게 닉네임 바꾸기 링크가 보인다" 대조군 테스트 추가
- **이유**: 게스트 모드 테스트는 링크가 "없다"만 확인하므로, 링크가 아무에게도 안 그려져도 통과하는 빈틈을 대조군으로 막음

#### 게스트 모드 테스트 갱신
- **파일**: `test/features/user/presentation/pages/my_page_guest_mode_test.dart`
- **변경 내용**: 게스트에게 닉네임 바꾸기·약관 및 정책·탈퇴하기가 숨고 "로그인하러 가기"만 보이는지 새 디자인 문구 기준으로 검증
- **이유**: 게스트는 계정이 없어 닉네임 변경·약관·탈퇴 진입점 자체가 없어야 함

#### 사용자 노출 문구 정비 (UX 라이팅 가이드 적용)
- **파일**: `lib/core/errors/app_exception.dart`, `lib/core/services/remote_config/update_dialog_helper.dart`, `lib/features/auth/data/repositories/auth_repository_impl.dart`, `lib/features/auth/presentation/pages/nickname_setup_page.dart`, `lib/features/collection/presentation/pages/collection_detail_page.dart`, `lib/features/favorite/presentation/pages/favorite_page.dart`, `lib/features/user/data/repositories/user_repository_impl.dart`, `test/features/auth/presentation/pages/nickname_setup_page_settings_test.dart`
- **변경 내용**: 사용자에게 노출되는 문구를 해요체·능동형·긍정형 기준으로 통일. 에러 메시지는 "~하지 못했어요. 잠시 후 다시 시도해 주세요." 패턴, 다이얼로그 왼쪽 버튼은 '닫기'/'나중에'로 통일. 관련 테스트의 기대 문구도 함께 갱신
- **이유**: 화면 개편과 함께 앱 전반의 보이스톤을 일관되게 정리

### 🔧 주요 변경사항 상세

#### _ProfileHeader — 프로필 헤더
- 좌측에 닉네임(display26), 우측에 "닉네임 바꾸기 ›" 텍스트 링크 배치
- 닉네임은 최대 10자 허용이라 넘치면 줄바꿈 대신 줄임표(ellipsis) 처리
- 텍스트 링크지만 터치 영역은 최소 높이 48을 확보
- 게스트는 바꿀 계정 자체가 없으므로 링크를 렌더링하지 않음 (`onEditTap: null`)
- 링크 탭 시 현재 닉네임을 쿼리 파라미터로 실어 닉네임 변경 화면으로 push

**특이사항**:
- 아바타(프로필 이미지)는 검토 후 이번 개편에서 제외. 헤더는 닉네임 + 링크만으로 구성

#### _StatsCard — 수집 통계 카드
- 기존 카드 2장을 카드 1장으로 합치고 `VerticalDivider`로 2분할: 좌측 수집률(%), 우측 모은 도감(개수)
- 각 칸은 라벨 + 셰브론 + 강조 수치(primary 색) 구성
- 카드 전체가 `InkWell` — 탭하면 도감 탭(`RoutePaths.collection`)으로 이동
- `IntrinsicHeight`로 구분선이 양쪽 칸 높이에 맞게 그려지도록 처리

#### _MenuRow — 메뉴 리스트 행
- 약관 및 정책 / 로그아웃 / 탈퇴하기를 카드·버튼 대신 헤어라인 `Divider`(1px)로 구분한 리스트 행으로 전환
- 각 행은 제목 + 우측 셰브론, 최소 높이 56 확보
- 탈퇴하기 행은 danger 색 제목 + "모든 기록을 완전히 지워요" 경고 subtitle 유지
- 탈퇴 진행 중에는 셰브론 자리에 스피너를 표시하고 로그아웃·탈퇴 행 탭을 잠가 중복 요청 방지

#### 탈퇴/로그아웃 로직 — 무변경
- '탈퇴하기' 문구(또는 delete) 직접 입력 확인 다이얼로그, 404 `MEMBER_NOT_FOUND` 멱등 처리, 로컬 정리 실패 시에도 세션 종료(`forceLogout`) 등 기존 플로우 그대로 유지
- 이번 작업은 진입점 UI(카드 버튼 → 메뉴 행)만 교체
