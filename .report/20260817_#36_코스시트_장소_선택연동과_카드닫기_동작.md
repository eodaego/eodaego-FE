# 코스 시트 장소 선택 연동과 카드 닫기 동작

### 📌 작업 개요

지도 하단 코스 시트(`CourseSheet`)와 장소 카드(`PlaceInfoCard`) 사이의 상호작용을 다듬는 이슈 #36 후속 작업. 시트 목록에서 고른 장소가 지도 마커 선택과 같은 동작으로 이어지도록 하는 연동, 그리고 카드를 닫기 버튼 대신 바깥을 눌러 닫는 동작을 `map_page_test.dart`에서 검증한다.

### 🎯 구현 목표

- 코스 시트 목록의 각 행을 누르면 지도에서 같은 장소의 마커를 고른 것과 동일하게 동작
- 선택된 장소는 시트 목록에서도 카테고리 틴트로 짚어 표시
- 장소 카드는 닫기 버튼 없이, 카드 바깥(지도)을 누르면 닫히고 카드 자체를 누르면 유지
- 다른 마커를 바로 눌렀을 때 카드가 한 번에 전환(닫기 탭을 따로 소모하지 않음)

### ✅ 구현 내용

#### 코스 시트 — 장소 행 선택과 지도 연동

- **파일**: `lib/features/map/presentation/widgets/course_sheet.dart`
- **변경 내용**: `CourseSheet`가 `onPlaceTap`(행을 눌렀을 때 지도 마커 선택과 같은 동작으로 이어주는 콜백)과 `selectedPlaceName`(현재 선택된 장소 이름)을 받는다. `_PlaceRow`는 `place.name == selectedPlaceName`일 때 `place.category.tint` 배경과 `place.category.dark` 마커 색으로 선택 표시를 하고, 수집 여부는 `checkColor: place.collected ? place.category.dark : null`로 마커 체크 뱃지에 반영
- **이유**: 마커가 겹쳐서 안 보이는 장소가 실제 지도에서 흔해, 시트 목록이 마커 선택의 유일한 입구가 되는 경우를 지원. 목록과 지도가 같은 카테고리색·수집 표시 규칙을 공유해야 두 UI가 같은 장소를 가리키는 것으로 읽힘

#### 시트 핸들 고정 — 스크롤 시트 안에서 자리 유지

- **파일**: `lib/features/map/presentation/widgets/course_sheet.dart`
- **변경 내용**: 드래그 핸들(`handleKey`)을 `PinnedHeaderSliver`로 감싸 `CustomScrollView` 안에 두되 목록이 스크롤돼도 제자리에 고정. 핸들 자체가 시트를 접고 펼치는 드래그 제스처를 받아야 하므로 스크롤뷰 바깥으로 빼지 않음
- **이유**: 핸들을 스크롤뷰 밖에 두면 고정은 되지만 손잡이로 시트를 끌 수 없게 됨 — 두 요구(고정 표시 + 드래그 가능)를 `PinnedHeaderSliver`로 동시에 만족

#### 장소 카드 닫기 동작 테스트

- **파일**: `test/features/map/presentation/map_page_test.dart`
- **변경 내용**: `장소 카드 닫기` 그룹에 세 케이스 추가
  - `closes_when_the_map_around_the_card_is_tapped`: 카드 바깥 빈 자리(약도 좌하단 구석)를 누르면 카드가 닫힘
  - `stays_open_when_the_card_itself_is_tapped`: 카드 안 텍스트를 눌러도 카드는 유지
  - `switches_straight_to_another_marker_in_one_tap`: 카드가 열린 채로 다른 마커를 바로 누르면 탭 한 번으로 새 장소 카드로 전환
  - 시트 핸들이 목록 스크롤과 무관하게 자리를 지키는 `keeps_the_sheet_handle_in_place_while_the_list_scrolls` 케이스도 함께 있음
- **이유**: 바깥 탭을 지도로 그대로 흘려보내는 설계라, 배리어가 탭을 삼키면 "닫기 한 번 + 다시 열기" 두 번이 필요해진다. 마커 전환이 한 탭으로 되는지가 이 설계의 핵심 검증 지점

### 🔧 주요 변경사항 상세

#### 카드 바깥 탭을 지도로 흘려보내는 이유

닫기 버튼을 없애고 카드 바깥을 눌러 닫는 방식으로 바꾸면서, 바깥 탭을 소모하는 배리어 대신 지도로 그대로 전달되게 했다. 이 덕분에 카드가 열린 상태에서 다른 마커를 바로 눌러도 한 번의 탭으로 카드가 전환된다. 테스트에서 `_marker(1)` → `_marker(2)`를 연속으로 눌러 이 동작을 확인한다.

**특이사항**:
- `_emptySpotOnMap`은 약도의 좌하단 구석처럼 마커도 카드도 없는 지점을 계산해 사용 — 실제 마커나 카드 위젯과 겹치면 의도와 다른 탭 대상을 누르게 됨
- `_marker(visitOrder)` 파인더는 위치가 아니라 방문 순서(`MapMarker.number`)로 찾는다. 약도가 선택된 마커를 겹친 무리 위로 올리려고 목록 끝으로 옮기기 때문에, 위치 기반으로 찾으면 마커를 한 번 누른 뒤 `.last`가 방금 누른 마커와 어긋날 수 있음
