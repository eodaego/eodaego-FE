## 1. 로깅 — 이모지 프리픽스

`print` 금지, `debugPrint`만 사용한다. 태그와 이모지를 함께 붙인다.

```dart
debugPrint('[FCM] ✅ 토큰 발급 성공');
debugPrint('[FCM] ⚠️ 토큰 없음 (시뮬레이터 또는 권한 거부)');
debugPrint('[FCM] ❌ 토큰 발급 실패: $e');
```

| 이모지 | 의미 | 사용 시점 |
| --- | --- | --- |
| ✅ | 성공 | 정상 완료 |
| ❌ | 에러 | 예외 발생 |
| ⚠️ | 경고 | 주의 필요 (기능은 계속 동작) |
| 🔄 | 진행 중 | 재시도, 갱신 등 |
| 📱 | 기기 정보 | 디바이스/플랫폼 정보 |
| 🔍 | 디버깅 | 상세 값 확인 |
| 💡 | 안내 | 원인 힌트 |

상세 디버깅 로그는 `kDebugMode` 블록 안에만 둔다.

## 2. 주석 — 영문 먼저, 한글 뒤

한 줄 주석은 영문 → 한글 순서로 두 줄을 쓴다.

```dart
// Singleton instance
// 싱글톤 인스턴스
static final FirebaseMessagingService _instance = ...;
```

공개 API에는 DartDoc(`///`)을 한글로 작성하고, 주의사항이 있으면 `**주의**:` / `Returns:` 절을 덧붙인다.

섹션 구분자는 아래 형식을 쓴다.

```dart
// ============================================
// Heading Styles (제목)
// ============================================
```
